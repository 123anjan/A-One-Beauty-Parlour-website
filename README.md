# Beauty Salon Landing Page

This is a modern single-page beauty salon website built with HTML, CSS, and JavaScript. The project focuses on a premium visual style, smooth user experience, and clear call-to-action sections to promote beauty and grooming services.

The website is designed as a polished landing page for a salon or beauty brand, with a warm luxury aesthetic and responsive layout for desktop and mobile users.

## Project Purpose

The main objective of this website is to:

- Present the salon as a trusted local beauty destination
- Showcase premium beauty and grooming services
- Improve customer engagement with direct contact CTAs
- Make the business easy to find through search and local discovery
- Support mobile-friendly browsing for on-the-go users
- Build a welcoming digital first impression for clients in Satna

## Website Features

The landing page includes the following sections and features:

- Hero banner with brand messaging and booking buttons
- Sticky top navigation bar
- About section describing the salon’s values and approach
- Service cards for hair care, skincare, makeup, and beauty essentials
- Why Choose Us section to highlight trust and convenience
- Gallery section with an interactive image lightbox
- Contact and enquiry call-to-action sections
- Smooth scroll and reveal-on-scroll animations
- Fully responsive layout for mobile, tablet, and desktop
- SEO-friendly page structure and metadata

## File Breakdown

### assets/index.html
This is the main page structure and contains all landing page sections, business details, CTAs, SEO metadata, and structured data markup.

### assets/css/style.css
This file contains the core design system, typography, layout styles, buttons, cards, hero section styling, and overall aesthetic.

### assets/css/animations.css
This file includes the motion effects used for fade-ins, scroll reveals, and decorative transitions.

### assets/css/responsive.css
This file handles responsiveness for different screen sizes including mobile and tablet breakpoints.

### assets/js/script.js
This file manages:

- mobile navigation toggle
- active menu highlighting on scroll
- reveal-on-scroll animation logic
- lightbox gallery behavior
- sticky header state changes
